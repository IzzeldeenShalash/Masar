# Masar: screen mockups

20 concept screens in five image boards. Created with the built-in image generation tool, using the initial Masar concept image as a visual reference.

These are static design concepts. Current implementation covers account access; the expanded resident and agency experiences illustrate a possible future direction. Text and demo dates inside generated images are illustrative.

## Prompt set / design brief

Shared prompt: High-fidelity mobile Masar UI mockups, four complete front-facing phones per landscape board. Match the original Masar concept: off-white #F6F7F4, navy #142B38, teal #087F82, sage #E6F1EE, amber status pills, rounded cards, readable English UI and Arabic brand. All organizations and locations fictional; clearly label future concept and demo data.

1. Welcome and account access: welcome, resident sign-in, create account, invited agency sign-in. No social login or password reset service.
2. Your neighborhood: resident home, neighborhood map, my reports, alerts. Shared Home / Reports / Alerts / Profile navigation.
3. Submit a report: describe the issue and add a photo, select location, review routing to Madar Roads, submission confirmation. Details / Location / Review stepper.
4. Tracking and account: report detail with progress timeline, agency update history, profile and settings, connection recovery preserving the saved session.
5. Agency workspace: Noor Electricity overview and metrics, assigned report queue, report detail, status update and completion photo with publish action.
